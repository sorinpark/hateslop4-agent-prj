# 부상 이력 기반 개인화 운동 피드백 AI Agent

부상 부위별 부하 쏠림 패턴을 실시간으로 관찰하고, 참고 정보형 피드백을 제공하는 AI Agent.
설계 배경/근거는 `기획.md`, 팀 일정은 `실행계획_3인.md` 참고.

---

## 기술 스택

| 영역 | 도구 |
|---|---|
| 관절 좌표 추출 | MediaPipe Pose |
| 특징 추출 / 영상 처리 | NumPy, OpenCV |
| 프론트엔드 | React |
| 백엔드 | FastAPI |
| DB | SQLite |
| LLM (개발) | Groq (LLaMA 3, 무료) |
| LLM (데모) | Gemini 1.5 Flash (무료 티어) |
| LLM (고도화) | Claude Haiku / GPT-4o mini |

---

## 추천 파이프라인

```
A. 환경 설정
        ↓
B. Perception — MediaPipe 관절 좌표 추출
        ↓
C. 카메라 가드 — 인식 신뢰도 체크 + 안내 문구
        ↓
D. 특징 추출 레이어 — 각도 / 좌우차이 / 흔들림 / 가동범위 / 부하 신호
        ↓                                    ↑
F. 실시간 피드백 LLM 호출  ←——————————  E. 온보딩 + 관찰 프로필 생성 (병렬 진행 가능)
        ↓
G. 실시간 피드백 UI
        ↓
H. 세션 데이터 저장 (DB)
       ↙ ↘
I. 리포트 생성 LLM     K. 다음 세션 권고 LLM (세션 간 비교)
       ↓                       ↓
J. 리포트 화면          L. 다음 세션 권고 화면
        ↓
M. 운동 확장 (검증되면 추가)
        ↓
N. 데모 시나리오 데이터 시뮬레이션
        ↓
O. 통합 / 예외처리 / 데모 리허설
```
