# 스쿼트 관절 인식 스파이크 실행 가이드

스쿼트 동작 시 무릎·발목·힙 관절이 카메라에 얼마나 잘 잡히는지 눈으로 확인하는 스크립트입니다.

---

## 실행 전 준비

```powershell
# 1. backend 폴더로 이동 (프로젝트 루트에서)
cd backend

# 2. venv 활성화 (Windows PowerShell)
.\venv\Scripts\Activate.ps1

# 3. 패키지 설치 (처음 한 번만)
pip install -r requirements.txt

# 4. 스크립트 실행
python vision/spike_webcam.py
```

처음 실행하면 모델 파일(`data/pose_landmarker.task`, 약 7 MB)을 자동 다운로드합니다.  
완료 후 웹캠 창이 열립니다. 종료는 **q**.

---

## 화면에서 뭘 보면 되나요?

| 표시 | 의미 |
|------|------|
| **초록 원** | 해당 관절이 잘 인식됨 (visibility ≥ 0.6) |
| **빨간 원** | 인식 불량 — 가려지거나 카메라 밖으로 벗어남 |
| 좌측 상단 `avg vis` | 6개 관절 평균 인식률 (1.0이 최고) |
| 콘솔 출력 | 동일한 평균 visibility 실시간 출력 |

관찰 포인트:
- 정면 촬영: 좌우 무릎·발목이 모두 초록인지 확인
- 측면 촬영: 카메라 반대쪽 관절이 빨강으로 바뀌는지 확인

## 결과 공유 방법

테스트 후 팀 채팅에 아래 형식으로 한 줄만 남겨주세요.

```
[각도] 정면 / 측면
[무릎] 초록 / 빨강
[발목] 초록 / 빨강
[평균 vis] 0.XX
[기타] 자유 메모 (예: 오른쪽 발목만 빨강, 어두운 방에서 인식 불안정)
```

예시:
```
[각도] 측면  [무릎] 초록  [발목] 반대쪽 빨강  [평균 vis] 0.71  [기타] 밝은 환경에서는 OK
```

## 문제가 생기면

1. **웹캠 권한 오류** (`cap.isOpened()` 실패)  
   → Windows 설정 → 개인 정보 → 카메라에서 앱 접근 허용 확인

2. **모델 파일 다운로드 실패**  
   → 네트워크 연결 확인 후 재실행. 또는 URL을 브라우저에서 직접 열어 `backend/data/` 에 저장

3. **`mediapipe` 관련 ImportError**  
   → `pip install mediapipe==0.10.*` 으로 버전 고정 후 재시도  
   (mediapipe Tasks API는 0.10 이상 필요)
